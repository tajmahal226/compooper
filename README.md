# Compooper

Find a bathroom worth sitting in.

Sister app to [Compisser](https://github.com/tajmahal226/compisser). Compisser points at the nearest toilet when you’re desperate. Compooper ranks bathrooms for a proper sit — cleanliness, a real stall, privacy — then points the compass at the throne.

## Run it

```bash
npm install
npm run dev
```

Then open the finder, allow location (or search a city), and sort by **Nicest sit**.

## Stack

React, TanStack Start, Tailwind, MapLibre, OpenStreetMap toilets.

## iPhone

Safari → Share → Add to Home Screen. The compass uses Motion & Orientation access.
